### Pré requis

g++ / gcc / mingw32

### Installation

```
git clone https://github.com/intel1337/rpss.git
```
Ensuite vous pouvez montrer ce que vous obtenez au final...

## Démarrage

-GCC GNU COMPILER :
```
gcc main.c && ./a.out
```

-G++ GNU COMPILER :
```
g++ main.c && ./a.out
```
