### Installation

```
git clone https://github.com/intel1337/rpss.git
```


## Utilisation

-GCC GNU COMPILER :
```
gcc main.c && ./a.out
```

-G++ GNU COMPILER :
```
g++ main.c && ./a.out
```

Evitez de modifier le save.txt pour ne pas rencontrer d'erreurs
